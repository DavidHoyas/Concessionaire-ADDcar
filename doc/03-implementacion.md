# 3. Implementación

---

## Entorno de desarrollo

- **Lenguaje:** Java
- **Framework:** Spring Boot (MVC)
- **Gestión del proyecto y compilación:** Maven
- **Librerías:** Lombok (menos código repetitivo), MapStruct (mapeo entre objetos) y Bean Validation (validaciones)
- **Gestión de versiones:** Git y GitHub
- **IDE:** Visual Studio Code
- **Documentación:** ficheros Markdown en la carpeta `doc/`
- **Máquina de desarrollo:** máquina virtual Debian 13 (VirtualBox) con 8 GB de RAM y 6 procesadores

---

## Implantación / puesta en marcha

- Desde el IDE: ejecutar la clase `ADDcarApplication`.

- La aplicación queda disponible en `http://localhost:8080`.
